# EnerTech

EnerTech es una plataforma web enfocada en el seguimiento y monitoreo del consumo de energía en los hogares.

El proyecto permite registrar información de las facturas de energía y consultar datos relacionados con el consumo de diferentes electrodomésticos.

## Funcionalidades

* Página principal con información sobre EnerTech.
* Misión, visión y objetivo del proyecto.
* Catálogo de electrodomésticos.
* Información del consumo aproximado de cada electrodoméstico.
* Registro de facturas de energía.
* Historial de facturas registradas.
* Modo claro y oscuro.
* Menú de navegación.
* Sección con información de los integrantes del proyecto.

## Información del proyecto

EnerTech busca ayudar a los usuarios a conocer mejor su consumo de energía mediante el registro de sus facturas y la consulta de información sobre electrodomésticos.

La plataforma también cuenta con una sección de misión, visión y objetivo, además de información sobre los integrantes del proyecto.

## Ejecución

Para instalar las dependencias:

```bash
pip install -r requirements.txt
```

Para ejecutar el proyecto:

```bash
python run.py
```

Luego se puede ingresar desde el navegador a:

```text
http://127.0.0.1:5000
```
